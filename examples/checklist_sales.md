# 买卖合同 · 审查清单

- 合同类型标识：`sales`
- 所属分类：物权类
- 交易实质：一方转移标的物所有权，另一方支付价款。
- 清单来源：common + sales

## 一、定立场

我代表哪一方？市场地位如何？本次审查要守住什么底线？
- [ ] 审查视角（甲方 / 乙方 / 中立）
- [ ] 谈判地位（强势 / 对等 / 弱势），决定哪些条款可谈、哪些必须守
- [ ] 商业底线与法律红线（红线不可让，底线可换算方案）

## 二、分层审查要点

### 1. 宏观：这笔交易本身能不能做、由谁做、要不要批？

- [ ] 对方主体是否存在、是否适格？营业执照、名称与签约主体是否一致？  `[致命]`
      主体不存在或名称不一致，合同可能无法约束预期相对人，先查登记信息再谈条款。
      依据：民法典第143条
- [ ] 签约人有无代表权或代理权？是否已尽到合理审查义务？  `[致命]`
      法定代表人越权签约的效力取决于相对人是否善意；应核验授权文件、决议与印章来源。
      依据：合同编通则解释第20条
- [ ] 合同名称与约定的权利义务是否一致？会不会被认定为名实不符？  `[重要]`
      裁判按合同内容而非名称认定关系，名为合作实为借贷一类的安排会被重新定性。
      依据：合同编通则解释第15条
- [ ] 标的是否合法、可否流转？交易结构是否触碰强制性规定或公序良俗？  `[致命]`
      违反效力性强制性规定的合同无效，且不因双方约定而改变。
      依据：民法典第153条
- [ ] 本次交易是否属于依法应当办理批准、登记、备案的情形？  `[重要]`
      需批准的合同在批准前未生效，报批义务条款本身独立有效，应明确由谁在何时报批。
      依据：民法典第502条
- [ ] 出卖人是否为标的物的所有权人或已获合法处分授权？  `[致命]`
      无权处分不当然导致合同无效，但会阻断履行，须核查权属凭证或授权链条。
      依据：民法典第595条

### 2. 中观：这份合同能不能生效、好不好用？

- [ ] 合同成立与生效条件是否写明？是否附条件、附期限？  `[一般]`
      依法成立的合同自成立时生效，除法律另有规定或当事人另有约定。
      依据：民法典第465条；民法典第502条
- [ ] 若使用格式条款，提供方是否履行了提示与说明义务？  `[重要]`
      未履行提示说明义务，对方可主张该条款不成为合同内容；加粗、单独确认、回执都是可用的证明手段。
      依据：民法典第496条；合同编通则解释第9条
- [ ] 民法典第四百七十条列举的一般条款是否齐备？  `[重要]`
      当事人、标的、数量、质量、价款、履行期限地点方式、违约责任、争议解决，缺一项就要评估能否依补充规则确定。
      依据：民法典第470条
- [ ] 同一交易是否存在多份文本？各文本之间的关系是否写明？  `[重要]`
      同一交易订立多份合同的，以虚假意思表示订立的一份无效；真实的多份则按成立顺序与实际履行认定是否变更。
      依据：合同编通则解释第14条
- [ ] 标的物毁损灭失的风险自何时起转移？是否与交付节点一致？  `[重要]`
      风险原则上随交付转移，另有约定从约定；风险转移点与所有权转移点可以分离，两者都要写明。
      依据：民法典第604条

### 3. 微观：每一条写得对不对、全不全、能不能执行？

- [ ] 违约金比例是否可执行？是否明显超出可预见损失？  `[重要]`
      超过损失百分之三十的一般会被认定为过分高于损失而调减；区分迟延履行违约金与解约违约金。
      依据：民法典第585条；合同编通则解释第65条
- [ ] 违约金条款是否留有举证与调整的空间，而非约定「不得调整」？  `[一般]`
      约定不得调整违约金的不予支持；主张调减的违约方负举证责任，非违约方主张合理的也须举证。
      依据：合同编通则解释第64条
- [ ] 损失赔偿范围是否限定在可预见范围内？是否排除间接损失？  `[重要]`
      赔偿额相当于违约造成的损失，包括可得利益，但不超过违约方订立时可预见的范围。
      依据：民法典第584条
- [ ] 不可抗力的定义、通知义务与证明期限是否写明？  `[一般]`
      不可抗力部分或全部免责，但须及时通知并在合理期限内提供证明；迟延履行后发生的不免责。
      依据：民法典第590条
- [ ] 长期合同是否预留情势变更的重新协商机制？  `[一般]`
      基础条件发生不可预见、非商业风险的重大变化时可请求重新协商乃至变更解除；事先约定排除该条适用无效。
      依据：民法典第533条；合同编通则解释第32条
- [ ] 解除条件是否与法定解除情形衔接？解除权的行使程序是否明确？  `[重要]`
      约定解除不必与法定解除一致，但应明确通知方式与解除后果；法定解除的五种情形是兜底。
      依据：民法典第563条
- [ ] 违约救济手段是否完整（继续履行、补救、赔偿）？是否与违约金重复计算？  `[一般]`
      约定违约金与继续履行可以并存，但就同一损失不得重复受偿。
      依据：民法典第577条
- [ ] 质量标准是否明确到可检验？是国标、行标、企标还是封样？  `[重要]`
      质量要求不明确会同时抬高验收争议与举证成本，宜写明标准编号并约定替代顺序。
      依据：民法典第615条
- [ ] 是否约定了检验期限与通知方式？逾期通知的后果是否提示到位？  `[重要]`
      怠于通知可能被视为数量质量符合约定；未约定检验期限时，二年是最长保护期，有质量保证期的从其约定。
      依据：民法典第621条
- [ ] 价款数额、支付方式与时间是否明确？是否含税、含运费？  `[重要]`
      数额与支付方式约定不明时适用补充规则，结果未必符合预期，宜直接写明。
      依据：民法典第626条

## 三、条款标准

### 争议解决条款　`必备`

必备要素：
- [ ] 协商优先的期限
- [ ] 诉讼或仲裁二选一，不得约定不明
- [ ] 仲裁机构名称准确唯一
- [ ] 协议管辖法院须与争议有实际联系，且不违反级别管辖与专属管辖

常见问题：约定「既可诉讼又可仲裁」；管辖法院约定不明或指向不存在的法院

建议文本（按交易调整变量后再用）：

> 因本合同引起的或与本合同有关的任何争议，双方应先友好协商解决；协商不成的，任何一方均可向【被告住所地/合同履行地/合同签订地】人民法院提起诉讼。【若选仲裁：均应提交【仲裁委员会全称】按照该会届时有效的仲裁规则仲裁，仲裁裁决是终局的，对双方均有约束力。】

依据：民法典第470条

### 保密条款　`必备`

必备要素：
- [ ] 保密信息的范围
- [ ] 保密期限（含合同终止后）
- [ ] 例外情形（已公开、法定披露）
- [ ] 违反保密义务的责任

常见问题：保密范围过宽或过窄；未约定合同终止后是否继续保密

建议文本（按交易调整变量后再用）：

> 双方对因履行本合同而获知的对方商业秘密及其他标明保密的信息负有保密义务，未经对方书面同意不得向任何第三方披露或用于本合同以外的用途。下列信息不属于保密信息：已公开、接收方在披露前已合法持有、独立开发并有充分证据证明、自无保密义务的第三方合法取得。保密义务自知悉该信息之日起持续【三】年，本合同终止或解除后继续有效。

依据：民法典第509条；民法典第501条

### 不可抗力条款　`必备`

必备要素：
- [ ] 不可抗力的定义或列举
- [ ] 通知义务与期限
- [ ] 证明材料的提供
- [ ] 免责范围与合同处理

常见问题：把商业风险也列入不可抗力；通知期限约定得过短

建议文本（按交易调整变量后再用）：

> 不可抗力指不能预见、不能避免且不能克服的客观情况，包括但不限于地震、台风、洪水等自然灾害，战争、动乱，以及政府依法采取的管制措施；市场行情变化、原材料涨价、资金短缺等商业风险不属于不可抗力。遭受不可抗力的一方应在【五】日内书面通知对方，并在【十五】日内提供有权机关出具的证明；未及时通知导致损失扩大的，对扩大部分不能免责。

依据：民法典第590条

### 通知与送达条款　`必备`

必备要素：
- [ ] 双方送达地址与联系人
- [ ] 送达方式及生效时间
- [ ] 地址变更的通知义务
- [ ] 约定送达地址可否适用于诉讼阶段

常见问题：仅有甲方地址；未约定地址变更后如何送达

建议文本（按交易调整变量后再用）：

> 双方确认下列地址为本合同履行及争议解决阶段的送达地址：甲方【地址、联系人、电话、电子邮箱】；乙方【地址、联系人、电话、电子邮箱】。以专人送达的，签收之日视为送达；以快递送达的，交寄后第三日视为送达；以电子邮件送达的，发送成功之日视为送达。一方变更送达地址的，应提前【五】日书面通知对方，未通知的仍以原地址为准，由此产生的不利后果由变更方承担。

依据：民法典第470条

### 合同生效、变更与解除条款　`必备`

必备要素：
- [ ] 生效条件（签字、盖章、批准）
- [ ] 变更须书面并经双方签署
- [ ] 解除的条件与程序
- [ ] 份数与效力顺序

常见问题：未写明生效是否需盖章；允许一方单方变更

建议文本（按交易调整变量后再用）：

> 本合同自双方法定代表人或授权代表签字并加盖公章之日起生效；法律规定应当办理批准等手续的，自手续办理完毕之日起生效，办理报批手续的义务由【】方承担。本合同的变更与补充须经双方协商一致并签署书面补充协议，任何一方不得单方变更。本合同一式【】份，双方各执【】份，具有同等法律效力。

依据：民法典第502条；民法典第563条

### 标的条款　`必备`

必备要素：
- [ ] 名称与规格型号
- [ ] 数量与计量单位
- [ ] 质量标准或封样
- [ ] 是否允许溢短装及比例

常见问题：描述笼统，未写规格型号；数量没有计量单位

建议文本（按交易调整变量后再用）：

> 出卖人向买受人提供下列标的物：品名【】，规格型号【】，数量【】（计量单位：【】），质量标准【国家标准编号/行业标准编号/封样编号】。允许溢短装的，溢短装比例为【】%，价款按实际交付数量结算。

依据：民法典第596条

### 价款与结算条款　`必备`

必备要素：
- [ ] 单价与总价
- [ ] 是否含税及发票类型
- [ ] 结算方式与付款节点
- [ ] 币种与汇率风险

常见问题：只写总价未写单价；未写明是否含税

建议文本（按交易调整变量后再用）：

> 本合同价款为人民币【】元（大写：【】），其中单价为每件人民币【】元。上述价款【含/不含】增值税，税率为【】%，出卖人应开具【增值税专用发票/增值税普通发票】。买受人应于【交付验收合格后十】个工作日内以【银行转账】方式支付；分期支付的，各期金额与时间：【安排】。

依据：民法典第626条

### 交付与验收条款　`必备`

必备要素：
- [ ] 交付时间与地点
- [ ] 运输方式与运费承担
- [ ] 验收标准、期限与程序
- [ ] 验收不合格的处理

常见问题：验收期限过短或未约定；未约定验收不合格后的补救路径

建议文本（按交易调整变量后再用）：

> 出卖人应于【日期】前将标的物交付至【地点】，运输方式为【】，运费由【】方承担。买受人应在收到后【七】日内按本合同约定的质量标准验收并书面提出异议，逾期未提出的视为数量与外观符合约定，隐蔽质量问题不受此限。验收不合格的，出卖人应在【十】日内免费修理、更换或补足；经两次更换仍不合格的，买受人有权解除本合同并要求赔偿损失。

依据：民法典第596条；民法典第621条

### 所有权与风险转移条款　`必备`

必备要素：
- [ ] 所有权转移时点
- [ ] 风险转移时点
- [ ] 是否保留所有权
- [ ] 保险的投保与受益人

常见问题：未区分所有权转移与风险转移；约定保留所有权但未办登记

建议文本（按交易调整变量后再用）：

> 标的物的所有权自【交付时/买受人付清全部价款时】起转移至买受人；毁损、灭失的风险自交付时起由买受人承担，法律另有规定或双方另有约定的除外。出卖人保留所有权的，买受人付清价款前标的物所有权不转移，出卖人有权依法办理所有权保留登记。

依据：民法典第604条

### 质量保证与售后条款　`可选`

必备要素：
- [ ] 质保期起算点与长度
- [ ] 质保范围与除外情形
- [ ] 维修或更换的响应时限

常见问题：质保期起算点不明确

建议文本（按交易调整变量后再用）：

> 标的物质保期为自验收合格之日起【十二】个月。质保范围包括材料与工艺缺陷，不包括因买受人使用不当、自行改装或不可抗力造成的损坏。质保期内出现质量问题的，出卖人应在接到通知后【四十八】小时内响应，并在【七】日内免费维修或更换。

依据：民法典第615条

## 四、风险信号词

| 信号 | 等级 | 命中词 | 说明 |
| --- | --- | --- | --- |
| 最终解释权条款 | 重要 | 最终解释权、最终解释、解释权归 | 由一方单方保留解释权，属于加重对方责任、排除对方主要权利的格式条款，可能不成为合同内容。 |
| 概不负责的全面免责 | 致命 | 概不负责、概不承担、不承担任何责任、免除全部责任 | 全面免除自身责任的表述，若属格式条款且未合理提示，对方法定责任无从追究，条款效力存疑。 |
| 单方变更条款 | 重要 | 单方变更、有权单方面修改、自行调整、无需另行通知 | 允许一方不经协商单方变更合同内容，动摇合同的对价基础，应改为协商一致并设置通知期。 |
| 放弃救济权利的表述 | 致命 | 放弃诉讼、放弃仲裁、不得提起诉讼、放弃抗辩 | 约定放弃诉权、仲裁权或抗辩权，排除对方的司法救济途径，通常不产生效力。 |
| 违约金畸高 | 重要 | 按合同总额的百分之五十、合同总额的百分之五十、百分之五十的违约金 | 明显超出可预见损失的违约金，对方可请求调减，超过损失百分之三十的一般会被认定过高。 |
| 自动续约且无退出机制 | 一般 | 自动续约、自动续期、自动顺延 | 自动续约条款应同时约定不续约的通知方式与提前期，否则可能被认定为加重对方负担。 |
| 验收期短至无法完成检验 | 重要 | 验收期为三日、验收期为3日、逾期视为验收合格 | 验收期过短或约定逾期即视为合格，会把标的物瑕疵风险不当转嫁给买方，须与检验实际所需时间匹配。 |
